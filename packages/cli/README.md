# moldig

CleanMyMac for your AI setup: scan, review and clean the skills, MCP servers, context files, memories and cache that AI coding harnesses (Claude Code, Codex, Cursor, Gemini CLI, Copilot, OpenCode) leave across your projects.

```sh
npx moldig
```

Requires Node.js >= 22.18. Under construction: this version only prints a banner.
